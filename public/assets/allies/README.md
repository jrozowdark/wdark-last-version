Place ally/client logos in this folder using one of these extensions:
- `.webp` (preferred)
- `.png`
- `.svg`

The UI will try these file names in this order:
1. `<slug>.webp`
2. `<slug>.png`
3. `<slug>.svg`

Expected slugs:
- `acquia`
- `sos-consulting`
- `universidad-de-las-americas`
- `denicolas`
- `tbwa`
- `quadi`
- `yr`
- `vml`
- `conafiz`
- `onix-digital`
- `proninez`
- `tecnobi`
- `hogarth`
- `inclup`
- `ogilvy-mather`
- `micrositios`
- `ariadna`
- `outer-space-coders`

Notes:
- Light logos should keep transparent background when possible.
- For logos that are too dark, upload a light-version file using the same slug.

Recommended visual surfaces per logo:
- dark: acquia, denicolas, quadi, proninez, inclup, ogilvy-mather, outer-space-coders
- light: sos-consulting, universidad-de-las-americas, tbwa, yr, vml, conafiz, onix-digital, tecnobi, hogarth, micrositios, ariadna
